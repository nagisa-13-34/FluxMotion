## 🔮 将来構想

### 14. Script / Plugin システム
ユーザーやサードパーティがFluxMotionの機能を拡張できるプラグイン基盤。
AEのエクスプレッションやスクリプトのように、自動化やカスタムエフェクトを実現する。

- [ ] プラグインAPI設計（レイヤー操作/レンダリング/UI拡張のインターフェース定義）
- [ ] JavaScriptベースのスクリプトエンジン統合
- [ ] エクスプレッション対応（プロパティ値をスクリプトで動的に計算）
- [ ] プラグインのインストール/管理UI
- [ ] プラグインマーケットプレイス（将来）

技術的な選択肢:
- Tauri側でV8/Denoを埋め込んでサンドボックス実行する方式
- WebWorkerでプラグインを隔離実行する方式
- WASMプラグイン（Rust/C++で書かれた高速プラグイン対応）

ライセンスの観点から、プラグインエコシステムを育てるにはMITライセンスが最適。
GPLだとプラグインのライセンスにも制約がかかるので商用プラグインが作りにくくなる。

## 2026-06-17 更新履歴

### 新機能
- **ツールオプションバー**: 選択中のツールに応じたオプション設定（色、線の太さなど）を上部に動的に表示
- **キャンバス直接テキスト入力**: テキストツールでキャンバスをクリックし、そのまま空の状態から入力可能に
- **テキストエリア自動リサイズ**: テキスト入力時に文字数や改行に応じて入力枠が自動で広がるように改善
- **テキスト入力の挙動修正**: 日本語入力（IME）の変換確定時にEnterキーで入力が終了してしまう問題を解消
- **ペンツールの機能強化**: 既存のパスの頂点をクリックして削除、線上のクリックで頂点の追加に対応
- **マスク/シェイプ切替**: ペン/シェイプツール使用時に、レイヤーが選択されている場合はマスクを作成するかシェイプを作成するかアイコンで選択可能に
- **UIの洗練化**: 選択されていないレイヤーの不要なバウンディングボックス（うっすらとした枠線）を非表示にし、プレビューをよりクリアに

## 2026-06-11 更新履歴

### 新機能
- **リサイズハンドル**: プレビュー上で選択レイヤーの8方向リサイズが可能に
- **ツールショートカット**: V(選択), H(手のひら), T(テキスト), Q(シェイプ), G(ペン)
- **クリップボード操作**: コピー/ペースト/カット/複製の実装完了（アニメーション含む）
- **全選択**: Ctrl+A で全レイヤー選択
- **メディアインポート**: ファイル→メディアをインポート / Ctrl+I で画像/動画レイヤー追加
- **画像/動画レンダリング**: Canvas2Dで画像・動画レイヤーの描画対応
- **フレームエクスポート**: 現在のフレームをPNGで書き出し（Ctrl+Shift+E）

### バグ修正
- Ctrl+A が修飾キーなしブロックにあり動作しない問題を修正
- シェイプ描画の座標がコンテナ基準でずれる問題を修正
- リサイズ/ドラッグ中にカーソルが元に戻る問題を修正（body cursorロック）
- メニュー外クリックでドロップダウンが閉じない問題を修正
- Tキーショートカットがツール切り替えのみでレイヤー追加しない問題を修正
- Layout型のTypeScriptエラー修正（`Layout` → `ILayoutApi`）
- 未使用の`handleAltClick`関数を削除
